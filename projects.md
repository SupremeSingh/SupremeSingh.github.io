  <h1 id="projects-heading" class="section-heading">Projects</h1>
  <ul class="post-list post-list-archive project-list">
    <li>
      <h2 class="post-list-title"><a href="https://github.com/SupremeSingh/rl_ms_project">SLICE</a></h2>
      <p>A reinforcement learning project that asks whether a small critic can help a language model learn to solve math problems. SLICE compresses hidden states from a frozen language model into 768 features and fits a small linear head from verified answers across PPO updates.</p>
    </li>
    <li>
      <h2 class="post-list-title"><a href="https://github.com/SupremeSingh/Awesome-ZK">Awesome-ZK</a></h2>
      <p>A practical introduction to zero-knowledge proofs for developers, combining conceptual and mathematical primers with hands-on Cairo examples and an ERC-20 implementation. It includes testing, JavaScript integrations, and a few case studies to connect the fundamentals to real applications.</p>
    </li>
    <li>
      <h2 class="post-list-title"><a href="https://github.com/SupremeSingh/AlphaToe">AlphaToe</a></h2>
      <p>An exploration of how different reinforcement learning and search methods play Ultimate Tic-Tac-Toe. It uses PPO and Monte Carlo tree search as baselines and experiments with CNN and Transformer versions of AlphaZero, as well as a simplified Gumbel AlphaZero agent.</p>
    </li>
    <li>
      <h2 class="post-list-title"><a href="https://github.com/SupremeSingh/AssessEngine">AssessEngine</a></h2>
      <p>A computing education research project that asks how well AI-text detectors distinguish student answers from model-generated ones. It uses SnapJudge to compare student and DeepSeek responses to short science questions and explores how rewriting those questions affects detection.</p>
    </li>
  </ul>
